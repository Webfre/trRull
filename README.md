# trRull — GYM ROULETTE

Олдскульный клуб домашних тренировок: красный игровой автомат, три упражнения на день и мультяшный тренер. React + TypeScript + Vite. Без бэкенда и регистрации.

## Запуск

Нужен Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Открой `http://127.0.0.1:5173`. Проверки и сборка:

```sh
npm test
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Относительные пути позволяют разместить его в подпапке, включая GitHub Pages `/trRull/`.

## Что работает

- Три барабана с последовательной остановкой и случайным объёмом упражнений.
- Одна прокрутка в календарные сутки по локальному времени устройства. Результат сохраняется до анимации и переживает перезагрузку страницы.
- Отдельная отметка каждого упражнения, серии дней, журнал и четыре награды.
- Имя в клубной карте, включение упражнений, индивидуальные минимумы и максимумы, необязательный звук.
- Двенадцать упражнений. Турник и брусья по умолчанию исключены; их можно включить в настройках.
- Персонаж внизу главной: 200 авторских шуток и подбадривающих реплик, анимация и речевое облачко. До трёх новых реплик в сутки без повторов.
- Мобильная компоновка, управление с клавиатуры, диалоги с удержанием фокуса, режим уменьшенного движения.
- Шрифты и персонаж хранятся в проекте: интерфейс не зависит от внешних CDN.

Настройки и результаты сохраняются в `localStorage` под ключом `gym-roulette-v1`. Это локальная демонстрация: данные не синхронизируются между устройствами, а очистка данных браузера удаляет прогресс. Для подсчёта серии нужно закрыть все три упражнения дня. Одинаковые упражнения могут выпадать несколько раз; каждый результат выполняется отдельно. Диапазоны используют естественный шаг упражнения: например, приседания — по 5 повторений от выбранного минимума, планка — по 10 секунд. Верхняя граница не превышается.

## Публикация на GitHub Pages

Публикация запускается вручную, отдельно от отправки кода.

1. В репозитории открой **Settings → Pages** и выбери **Source: GitHub Actions**.
2. Открой **Actions → Publish to GitHub Pages → Run workflow** для ветки `main`.
3. После успешной сборки адрес появится в разделе **Deployments → github-pages**. Для этого репозитория ожидаемый адрес: `https://webfre.github.io/trRull/`.

Workflow проверяет логику, собирает приложение и публикует только `dist/`. Сервер, база данных и секреты не нужны.

## Персонаж

`public/assets/coach.png` — отдельный PNG 1122 × 1402 с настоящим альфа-каналом: только персонаж, без фона. Можно использовать как стикер или иконку. Создан встроенным imagegen; описание генерации и удаления фона — в `docs/mascot-prompt.txt`.

Персонаж появляется только на главной странице, под тренировкой. Нажатие показывает случайную ещё не рассказанную реплику. Пока текст печатается, повторный клик раскрывает его целиком и не тратит следующую реплику. После трёх реплик следующее нажатие вызывает прощание: тренер уходит тренироваться и исчезает до следующего календарного дня по времени устройства. Прощание остаётся на экране ещё несколько секунд после появления полного текста.

История ID и дат, дневной лимит и уход тренера сохраняются отдельно от тренировок под ключом `gym-roulette-coach-v1`. Обновление страницы и переход в профиль не сбрасывают историю. В браузерах с Web Locks одновременные нажатия из разных вкладок обрабатываются по очереди; изменения синхронизируются через событие `storage`. На следующий день персонаж возвращается, включая случай, когда страница оставалась открытой. После всех 200 реплик он прощается окончательно: история не обнуляется и старые шутки не повторяются. Это юмор и поддержка, а не подборка медицинских фактов.

## Структура

- `src/App.tsx` — страницы клуба и локальное состояние.
- `src/components/` — рулетка, диалоги, настройки и иконки упражнений.
- `src/lib/workout.ts` — генерация заданий, календарь, прогресс и восстановление данных.
- `src/components/CoachCompanion.tsx` — персонаж, печать реплик, анимация и локальное сохранение.
- `src/data/coach-lines.ts` — 200 реплик с постоянными ID.
- `src/lib/coach.ts` — дневной лимит, история, выбор без повторов и возвращение после полуночи.
- `src/styles.css` — визуальная система и адаптивная компоновка.
- `tests/workout.test.mjs` — проверки ограничения на день, выполнения, серий, диапазонов и повреждённых данных.
- `tests/coach.test.mjs` — проверки каталога, лимита, сохранения, возвращения и исчерпания всех реплик.

Палитра: бумага `#eeeadf`, чернила `#282920`, красный `#ba392c`, оливковый `#4c6044`. Шрифты: Oswald и PT Sans, включая кириллицу. Иконки — Lucide.
